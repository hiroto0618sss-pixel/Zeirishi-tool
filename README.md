# 税理士業務ツール

税理士業務で使うツールを置くリポジトリです。実在の顧問先データは一切置きません（テスト・例はすべてダミーです）。

## 税務期限エンジン

顧問先の基本情報を入力すると、対象年（1月1日〜12月31日）に期限が来る申告・納付の一覧を日付順に表示し、CSVで書き出せるツールです。

- HTML + JavaScript だけで動きます（ビルド不要・外部ライブラリなし）。`index.html` をブラウザで開くだけで使えます。
- 入力内容はブラウザの中で計算するだけで、どこにも送信・保存しません。

### ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` / `app.js` / `style.css` | 画面 |
| `src/deadlines.js` | 期限計算ロジック（画面から独立。GAS・kintone でも再利用できる形） |
| `data/holidays.json` | 祝日データ（内閣府の公表CSVから生成） |
| `data/holidays.js` | `holidays.json` と同じ内容を `<script>` で読めるようにしたもの（`file://` で開いたときも動くように） |
| `scripts/update-holidays.mjs` | 祝日データの更新スクリプト |
| `test/deadlines.test.js` | テスト（`node:test`） |

### 入力項目

| 項目 | 対象 | 説明 |
| --- | --- | --- |
| 区分 | 共通 | 法人 / 個人 |
| 対象年 | 共通 | この年の1/1〜12/31に期限が来るものを表示 |
| 源泉所得税の納期の特例 | 共通 | 承認を受けているか |
| 決算月 | 法人 | 12か月の事業年度・月末決算が前提 |
| 申告期限の延長特例 | 法人 | 法人税・消費税それぞれ |
| 前期の法人税額 | 法人 | 中間申告の要否の判定に使用（空欄なら判定しない） |
| 前期の消費税額 | 法人 | 確定消費税額の国税分（地方消費税を除く）。中間申告の回数の判定に使用 |

### 出力

期限日・税目・手続・対象期間・根拠条文・備考。休日のために期限をずらした行には、休日調整前の法定の期限と、ずらした理由も表示します。CSV（UTF-8・BOM付き、Excelでそのまま開けます）でも書き出せます。

### 計算ルールと根拠

| 手続 | 期限 | 根拠条文 |
| --- | --- | --- |
| 法人税の確定申告 | 事業年度終了日の翌日から2か月以内（延長特例ありは+1か月） | 法法74①、75の2① |
| 法人税の中間申告 | 事業年度開始日以後6か月を経過した日から2か月以内。前期法人税額 ÷ 前期月数 × 6 が **10万円以下なら不要** | 法法71① |
| 消費税の確定申告（法人） | 課税期間の末日の翌日から2か月以内（延長特例ありは+1か月。法人税の延長特例を受けている法人に限る） | 消法45①、45の2① |
| 消費税の中間申告（法人） | 前期の確定消費税額（国税分）で回数を判定。**48万円以下: 不要／48万円超〜400万円以下: 年1回／400万円超〜4,800万円以下: 年3回／4,800万円超: 年11回**。各対象期間の末日の翌日から2か月以内。年11回の1回目は課税期間開始日から2か月を経過した日から2か月以内（延長特例法人は1・2回目が開始日から3か月を経過した日から2か月以内） | 消法42①④⑥ |
| 所得税の確定申告 | 翌年3/15 | 所法120① |
| 消費税の確定申告（個人） | 翌年3/31 | 措法86の4① |
| 所得税の予定納税 | 第1期 7/31、第2期 11/30（予定納税基準額15万円以上の場合） | 所法104① |
| 源泉所得税（原則） | 支払月の翌月10日 | 所法183①、199、204①ほか |
| 源泉所得税（納期の特例） | 1〜6月分は7/10、7〜12月分は翌年1/20 | 所法216 |
| 償却資産申告 | 1/31 | 地方税法383 |
| 法定調書・同合計表 | 1/31 | 所法225①、226①ほか |
| 給与支払報告書 | 1/31 | 地方税法317の6① |
| 休日による延長（国税） | 日曜・祝日・一般の休日（1/2・1/3）・土曜・12/29〜12/31に当たるときは翌日（さらに休日なら次の平日） | 通法10②、通令2②、通則法基本通達10条関係4 |
| 休日による延長（地方税） | 同上 | 地方税法20の5②、地方税法施行令6の18② |

消費税の中間申告のしきい値は、条文では月数で割った額で書かれています（前期税額 ÷ 前期月数 が400万円超で年11回、×3 が100万円超で年3回、×6 が24万円超で年1回）。前期が12か月なら、国税庁の資料にある年額（4,800万円・400万円・48万円）と同じ判定になります。

### 計算の前提と制限

- **「対象年」は期限日で区切ります。** 1/1〜12/31に期限（休日調整後）が来るものだけを表示します。たとえば納期の特例の「7〜12月分（翌年1/20期限）」は翌年の一覧に出ます。2026年の一覧には「2025年7〜12月分 → 2026/1/20」と「2026年1〜6月分 → 2026/7/10」が並びます。
- 法人の事業年度は12か月・月末決算を前提にしています。設立初年度・決算期変更・課税期間の特例には対応していません。
- 中間申告の判定には、入力した前期税額を、対象年に期限が来るすべての中間申告に当てはめています。前年度分の年11回中間申告の最終回のように、基礎になる事業年度が異なるものが混ざる場合は、その事業年度の実績で確認してください（画面にも警告を出します）。
- 法人税の延長特例は+1か月だけに対応しています（会計監査人設置法人などの最大4か月延長と、通算法人の2か月延長には未対応）。
- 予定納税は、要否（予定納税基準額15万円以上）を入力しないため、個人には常に表示し、備考に条件を書いています。
- 償却資産申告と給与支払報告書は、該当がある場合に必要な手続です（備考に記載）。

### TODO（確認できなかった点・未対応）

推測では埋めず、次の点を残しています。

1. **消費税の年11回中間申告で延長特例を受けている法人の1・2回目の期限**の条文が特定できていません。国税庁タックスアンサーNo.6609（注5）の記載どおりに実装しましたが、消法42条・45条の2の本文には該当する規定が見当たりませんでした。施行令などの根拠条文を確認する必要があります（画面の根拠欄は「消法42①（国税庁タックスアンサーNo.6609 注5）」と表示）。
2. **地方税の休日の扱いで、1/2・1/3が休日に当たるか**: 地方税法20条の5第2項は民法142条の休日と施行令6条の18第2項（土曜・12/29〜12/31）を指定しています。1/2・1/3を「その他の休日」とみなす扱いは国税の通達（通則法基本通達10条関係4）でしか確認できていません。地方税の公式資料（総務省など）での確認が必要です。現在は国税と同じく休日として扱っています。今の一覧に出る地方税の期限は1/31だけなので、計算結果には影響しません。地方税の手続を追加するときに確認が必要です。
3. **償却資産申告・給与支払報告書**は地方税のため、国税庁の資料ではなく地方税法の条文（e-Gov）だけで確認しています。市町村によっては受付日程を別途案内している場合があります。
4. **令和9年（2027年）以後の防衛特別所得税**: 国税庁No.2505によると、令和9年分以後の源泉徴収は「所得税・防衛特別所得税・復興特別所得税」になります。税目の表示名にはまだ反映していません（期限は同じ）。所得税の確定申告・予定納税の表示名も同様です。
5. **個人事業者の消費税の中間申告**は未対応です（今回の要件の範囲外）。
6. **法人住民税・法人事業税**などの地方税の申告期限は未対応です。
7. **法人税の中間申告の対象外**となる法人（公益法人等、新設法人の初年度、通算法人の特例など）は判定していません。普通法人を前提にしています。
8. **法定調書**は主なもの（源泉徴収票・支払調書など）を1/31としています。法定調書の種類ごとの提出期限は確認していないため、1/31以外の期限の法定調書があるかどうかは、国税庁「法定調書の作成と提出の手引」で確認が必要です。
9. **前期が12か月未満の場合**の中間申告の判定は、ロジック（`prevFiscalMonths`）では対応していますが、画面には入力欄がありません。
10. **祝日データは2027年まで**です（内閣府の公表分）。2028年以後を計算すると警告が出ます。内閣府が翌年分を公表したら、下の手順で更新してください。

### テストの実行

Node.js 18 以上で実行できます（依存パッケージはありません）。

```sh
npm test
# または
node --test
```

### 祝日データの更新

内閣府が新しい年の祝日を公表したら、次を実行して `data/holidays.json` と `data/holidays.js` を作り直し、コミットします。

```sh
npm run update-holidays
# ダウンロード済みのCSVを使う場合
node scripts/update-holidays.mjs path/to/syukujitsu.csv
```

### ロジックの再利用（GAS・kintone など）

`src/deadlines.js` は画面に依存しない1ファイルです。ブラウザではグローバル変数 `DeadlineEngine`、Node.js では `require('./src/deadlines.js')` で使えます。祝日データは引数で渡します。Google Apps Script では、このファイルと `data/holidays.js` をそれぞれスクリプトファイルとして貼り付ければ、`DeadlineEngine` と `JP_HOLIDAYS` がグローバルに定義されます。

```js
const engine = require('./src/deadlines.js');
const holidays = require('./data/holidays.json');

const { items, warnings } = engine.computeDeadlines(
  {
    entityType: 'corporation', // 'individual' なら個人
    year: 2026,
    fiscalEndMonth: 3,
    corpTaxExtension: false,
    consumptionTaxExtension: false,
    prevCorpTax: 1200000,        // 円。null なら中間申告を判定しない
    prevConsumptionTax: 5000000, // 円（国税分）。null なら中間申告を判定しない
    withholdingSpecial: true,
  },
  { holidays },
);
console.log(engine.toCsv(items));
```

各項目は `dueDate`（休日調整後の期限）、`statutoryDate`（法定の期限）、`shifted`、`shiftReason`、`tax`、`procedure`、`period`、`basis`（休日による延長の条文を含む）、`statutoryBasis`、`note` を持ちます。

## GitHub Pages で公開する

1. GitHub でこのリポジトリを開き、**Settings → Pages** を開きます。
2. **Build and deployment** の **Source** で「**Deploy from a branch**」を選びます。
3. **Branch** で公開したいブランチ（通常は `main`）と、フォルダ「**/ (root)**」を選び、**Save** を押します。
4. 1〜2分待つと、同じ画面の上部に公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が表示されます。そのURLを開くと税務期限エンジンが表示されます。

補足:

- ビルドは不要です。ブランチに push すると自動で反映されます（反映まで数分かかることがあります）。
- 無料プランの GitHub Pages は**公開リポジトリでのみ**使えます。非公開リポジトリで使う場合は有料プランが必要です。また、Pages で公開したページは誰でも閲覧できます。このツールは入力値を送信・保存しませんが、リポジトリには実在の顧問先データを置かないでください。
- ローカルで確認するときは `index.html` をダブルクリックで開くだけで動きます。
